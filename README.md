## 💻 Installation Locale

Pour consulter le wiki localement et bénéficier du rechargement à chaud (hot-reload), nous utilisons **Docker**.

### Prérequis
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) installé et lancé.

### Lancement
1. Clonez le dépôt :
   ```bash
   git clone <url-du-depot>
   cd wiki-v2
   ```
2. Démarrez le conteneur Zensical :
   ```bash
   docker-compose up
   ```
3. Accédez au wiki dans votre navigateur :
   👉 [**http://localhost:8000**](http://localhost:8000)
